# رُوبُو برای اندروید — پروژه سورس

این پروژه، پورت اندرویدیِ قابلیت‌های اصلی برنامهٔ دسکتاپ رُوبُو است. **این ZIP فایل APK نیست** و در این محیط کامپایل یا روی Poco/Arduino واقعی آزمایش نشده است.

## امکانات پیاده‌سازی‌شده در سورس
- اتصال USB-Serial به Arduino Mega با OTG، سرعت 9600 و فرمان‌های FORWARD/BACKWARD/LEFT/RIGHT/STOP.
- دکمهٔ توقف و توقف هنگام بسته‌شدن برنامه؛ حرکت زمان‌دار حداکثر ۵ ثانیه از ابزار Gemini.
- مکالمهٔ پیوستهٔ Gemini Live از طریق WebSocket، دریافت/ارسال صدای PCM، نمایش رونویسی‌ها و ابزارهای فراخوانی‌شده.
- ابزارهای Gemini: حرکت/توقف، فهرست فایل‌ها، خواندن فایل، جست‌وجو، بررسی ابتدایی نشانه‌های نحوی Python، پیشنهاد تغییر و پیشنهاد حذف.
- مدیریت فایل‌های پروژه در پوشهٔ خصوصی برنامه؛ واردکردن فایل از گوشی؛ پشتیبان قبل از تغییر/حذف؛ تأیید صریح کاربر پیش از اعمال تغییر یا حذف.
- کلید API در SharedPreferences خصوصی برنامه ذخیره می‌شود. آن را به کسی نده.

## محدودیت‌های مهم و صادقانه
- فایل‌های پروژه در گوشی با فایل‌های کامپیوتر `E:\Robo` یکی نیستند؛ باید فایل‌ها را به پوشه پروژه داخل اپ وارد کنی.
- بررسی نحوی Python در Android فقط بررسی ابتدایی توازن نشانه‌هاست و جایگزین AST/اجرای واقعی Python در نسخه کامپیوتر نیست.
- بازیابی پشتیبان به‌صورت دستی از پوشه `_RoboBackups` هنوز در رابط کاربری کامل نشده است؛ فایل‌های پشتیبان ایجاد می‌شوند.
- مدل Live پیش‌فرض در سورس `gemini-2.5-flash-native-audio-preview-12-2025` است؛ در صورت منسوخ‌شدن/عدم دسترسی مدل یا نداشتن سهمیه، باید نام مدل فعالِ حساب Gemini را تنظیم کنی.
- API key داخل اپ کلاینتی امنِ کامل محسوب نمی‌شود. برای استفاده شخصی آن را خصوصی نگه دار؛ سهمیه/هزینه API تابع حساب و سیاست‌های گوگل است.
- مکالمهٔ صوتی ممکن است به‌دلیل مدل/منطقه/اینترنت/مجوزها/سازگاری گوشی کار نکند؛ باید روی دستگاه واقعی آزمایش شود.

## ساخت APK
1. ZIP را استخراج کن.
2. در Android Studio گزینهٔ **Open** را بزن و پوشهٔ `RoboAndroid` را انتخاب کن.
3. صبر کن Gradle Sync کامل شود و وابستگی‌ها دانلود شوند.
4. از **Build → Build APK(s)** استفاده کن.
5. APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` است.
6. APK را روی گوشی نصب کن، مجوز میکروفون را بده، کلید Gemini را وارد کن، بعد OTG/Arduino را وصل کن.

## Arduino
برد باید اسکچ سازگار با فرمان‌های متنی سریال و baud rate برابر 9600 داشته باشد. اسکچ فعلی Arduino را فقط یک بار آپلود می‌کنی؛ پس از آن برای هر اجرا نیازی به آپلود مجدد نیست. ابتدا چرخ‌ها را از زمین بلند کن و STOP را آزمایش کن. برق موتورها را از منبع مناسب مدار تأمین کن، نه از USB گوشی.
